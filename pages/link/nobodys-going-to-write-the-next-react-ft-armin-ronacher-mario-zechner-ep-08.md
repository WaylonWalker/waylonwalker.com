GOATED Panel on this episode.  I thought the chat about PRs being Theater was
great.  I feel like I line up well with Armin on this one, I really enjoyed the
PR as a place to show "Hey I'm working on this", "What do you think".  200 line
prs were great.  Agents now submit 10k+ line prs and they are impossible to
read now.  Using the app for real as a user, or poking holes at the design in
an agent session is much more valuable than reading line by line anymore.  The
agents quickly went from writing shit code to code that is better than nearly
everyone.

The React point was interesting, and I like the analogy.  React is something I
feel anyone in the developer community can relate to.  If you've spent any time
online talking about tech before 2026 react would naturally come up.  Now it
doesn't.  We quickly stopped caring about the implementation details and caring
more about user experience, or pumping out slop depending on your perspective.
I feel this accross the board with a lot of my terminal setup or python
packages I loved to use.
