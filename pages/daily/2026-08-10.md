## plaindown features

### Mobile

Plaindown is working fantastic as a note editor from mobile, but has a few things hard to get to when you are raw doggin a phone with no keeb attached.  Pull up push down second footer with some buttons to help authorship.

* Upload image
* Favorite templates
* Fuzzy picker

Alternatively remove filename and words from footer in mobile mode.

### Desktop features

I cannot believe that its becoming something that I use on desktop.  Am I giving up my beloved nvim, no they are different, but there is something hyper specific here that is working.

* quickfix feed
* drag from sidebar into post to link
* control enter to commit
* diffs have `use remote` and `use mine` but no `merge`
* commit is a bit slow with no indication to what is being done, some slowdown for the api is expected, but something on the screen showing what's going on would help.  For sure disable and spin the commit button.
